The tenant's findings, oldest first by default; each node is the report's finding summary plus its audit, statement, category and period. ageDays is as of today in the tenant's time zone. Filter via `query:` search string. Allowed keys: audit, statement, category, state, period, firstFound

```graphql
findings(after: String, first: Int, query: String, reverse: Boolean, sortKey: FindingListItemSortKey): FindingListItemConnection
```

## Arguments

| Argument | Type | Description |
|---|---|---|
| `after` | [`String`](/graphql/scalars/string) | Return findings after this cursor (pageInfo.endCursor). A cursor belongs to its sortKey and reverse. |
| `first` | [`Int`](/graphql/scalars/int) | Return the first n findings, 1 to 100; default 50. |
| `query` | [`String`](/graphql/scalars/string) | A search string of key:value terms; see the field description for the keys. |
| `reverse` | [`Boolean`](/graphql/scalars/boolean) | Reverse the sort order. |
| `sortKey` | [`FindingListItemSortKey`](/graphql/enums/finding-list-item-sort-key) | The field to sort by. |

## Returns

[`FindingListItemConnection`](/graphql/objects/finding-list-item-connection)
