An audit's report for one morning, from the tenant of the API key.

```graphql
auditReport(audit: String!, date: String, period: String): AuditReportDocument
```

## Arguments

| Argument | Type | Description |
|---|---|---|
| `audit` | [`String!`](/graphql/scalars/string) | The audit's code, e.g. month-close. |
| `date` | [`String`](/graphql/scalars/string) | The morning to describe, YYYY-MM-DD; blank is today in the tenant's time zone. |
| `period` | [`String`](/graphql/scalars/string) | Which period's run, e.g. 2026-10 while October is extended; blank is the morning's own period. |

## Returns

[`AuditReportDocument`](/graphql/objects/audit-report-document)
