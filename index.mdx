Darpan checks that your order, refund, return and exchange records agree across Shopify, your OMS and NetSuite. This site is for the people who build on that: integrations and agents that read Darpan's findings, and engineers who run or change Darpan itself. Product guides for people using the app are at [docs.drpn.ai](https://docs.drpn.ai).

## What the API gives you

| | |
|---|---|
| **Read-only** | Queries only. Fix a record in the system it lives in; Darpan's next check closes the finding |
| **One tenant per key** | A key reads its own tenant's data and nothing else. A query cannot name a tenant |
| **One endpoint** | `POST https://api.drpn.ai/rest/s1/graphql/public` on hosted Darpan |
| **Self-describing** | `GET /rest/s1/graphql/sdl` returns the schema, with a description on every field |
