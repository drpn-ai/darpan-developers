A script reads `input` and returns one value. It can call the `d:` functions on this page and JEXL's own built-ins, and nothing else: no clock, no randomness, no network, so the same input always gives the same result.

## The d: functions

{/* functions:start (generated by scripts/generate_script_functions.py; do not edit by hand) */}
| Function | Returns |
| --- | --- |
| `d:dec(x)` | x as a decimal number (text or number); null stays null |
| `d:round(x, places)` | x rounded half-up to places decimals; d:round(x, 2) for money |
| `d:str(x)` | x as text |
| `d:lower(s) / upper(s) / trim(s)` | text case and surrounding spaces |
| `d:has(s, part)` | true when text s contains part |
| `d:replace(s, from, to)` | every from in s replaced with to (plain text, no patterns) |
| `d:split(s, sep)` | text s split on sep into a list |
| `d:join(list, sep)` | the list as one text, sep between items |
| `d:keys(map) / vals(map)` | a map's keys / values as a list |
| `d:pluck(list, field)` | field from each map in the list |
| `d:where(list, field, value)` | the maps in the list whose field equals value; size(...) counts them |
| `d:sum(list) / sum(list, field)` | the total of the numbers, or of field across maps |
| `d:groupCount(list, field)` | a map of each value of field to how many maps have it |
| `d:sorted(list) / distinct(list)` | the list sorted / with repeats removed |
| `d:sortBy(list, 'field')` | the maps ordered by field: '-field' descending, '^field' ignoring case, 'a,b' by several |
| `d:day(x)` | a date or timestamp as yyyy-MM-dd (UTC) |
| `d:daysBetween(a, b) / hoursBetween(a, b)` | whole days / hours from a to b (dates, timestamps or epoch ms) |
| `d:log(x)` | adds x to the run log and returns it |
{/* functions:end */}

## Built into JEXL

These need no `d:` prefix, so there is no `d:len`, `d:min` or `d:count`.

| Expression | Returns |
| --- | --- |
| `size(x)` | How many items a list or map holds, or characters in text. |
| `empty(x)` | True when `x` is null, empty text, or an empty list or map. |
| `a =^ b` / `a =$ b` | True when text `a` begins / ends with `b`. |
| `x =~ list` | True when `x` is in `list`. |
| `a ? b : c` | `b` when `a` is true, else `c`. |
| `a ?? b` | `a`, or `b` when `a` is null. |

## Limits

A script stops with an error when it passes any of these. The error names the limit and, where there is one, the line.

| | Expression (one line) | Script (variables, loops) |
| --- | --- | --- |
| Source | 2,000 characters | 64,000 characters |
| Work per run | 100,000 units | 2,000,000 units |
| Time per run | 250 ms | 2,000 ms |

Every run, in both profiles: text up to 65,536 characters, and lists or maps up to 10,000 items.

## Example

If `input.rows` is a list of maps, this counts the rows whose `status` is `OPEN` and logs the count:

```jexl
var open = d:where(input.rows, 'status', 'OPEN');
d:log(size(open));
'Open rows: ' + size(open)
```
